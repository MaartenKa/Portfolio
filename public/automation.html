Automatisering gebruiken om sneller, betrouwbaarder en herhaalbaar softwarekwaliteit te controleren.

AUTOMATION

Laat tests het werk doen.

Automatiseren van testen heeft verschillende voordelen. Door tests automatisch uit te voeren, kunnen ze sneller en vaker worden uitgevoerd. Dit bespaart tijd en zorgt ervoor dat testers zich kunnen richten op andere belangrijke taken. Ook wordt de kans op menselijke fouten kleiner. Vooral bij regression testing is automatisering handig, omdat dezelfde tests na iedere wijziging opnieuw uitgevoerd kunnen worden. Hierdoor kan de kwaliteit van de software beter en efficiënter worden gecontroleerd.

TECHNOLOGIE

Mijn automation stack

🎭

Playwright

Een testautomatiseringstool waarmee je webapplicaties automatisch kunt testen. Je kunt bijvoorbeeld een browser openen, op knoppen klikken, formulieren invullen en controleren of de juiste resultaten worden weergegeven. Playwright ondersteunt onder andere Chrome, Firefox en Safari en wordt veel gebruikt voor end-to-end testing.

⌨️

TypeScript

Typescript is op JavaScript gebaseerd. Het voegt onder andere types toe aan JavaScript, waardoor fouten eerder ontdekt kunnen worden. TypeScript wordt veel gebruikt bij het ontwikkelen van webapplicaties en kan ook worden gebruikt om tests te schrijven met Playwright.

⚙️

Node.js

Node.js is een omgeving waarmee je JavaScript buiten de browser kunt uitvoeren. Het wordt veel gebruikt om serverapplicaties en tools te bouwen. Bij Playwright wordt Node.js bijvoorbeeld gebruikt om testprogramma’s uit te voeren en testresultaten te verwerken.

⚙️

Cypress

Cypress is een testframework waarmee je voornamelijk webapplicaties automatisch kunt testen. Een groot voordeel van Cypress is dat het eenvoudig te installeren en te gebruiken is en beschikt over een gebruiksvriendelijke testomgeving.

⚙️

Dev tools

Developer Tools zijn ingebouwde hulpmiddelen in moderne webbrowsers waarmee ontwikkelaars en testers webapplicaties kunnen inspecteren, testen en debuggen. Met Developer Tools kun je onder andere de HTML- en CSS-structuur bekijken, JavaScript-fouten onderzoeken, netwerkverkeer analyseren en het gedrag van een webpagina tijdens het gebruik controleren.

TESTS

Wat ik automatiseer

🔗

End-to-End Tests

Het testen van een complete applicatie van begin tot eind. Hierbij wordt gecontroleerd of een volledige gebruikershandeling goed werkt, Hiermee controleer je of alle onderdelen van het systeem goed samenwerken.

🖥️

UI Tests

Controleren of de gebruikersinterface van een applicatie goed werkt. Hierbij test je bijvoorbeeld of knoppen, menu’s, formulieren en links correct reageren wanneer een gebruiker ermee werkt

🔌

API Tests

Meten of een API correct werkt en goed communiceert tussen verschillende systemen of onderdelen van een applicatie. Hierbij test je bijvoorbeeld of de juiste gegevens worden verstuurd, ontvangen en verwerkt en of de API de juiste foutmeldingen geeft.
