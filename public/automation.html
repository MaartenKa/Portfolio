AUTOMATION

Laat tests het werk doen

Automatiseren van testen heeft verschillende voordelen. Door tests automatisch uit te voeren, kunnen ze sneller en vaker worden uitgevoerd. Dit bespaart tijd en zorgt ervoor dat testers zich kunnen richten op andere belangrijke taken. Ook wordt de kans op menselijke fouten kleiner. Vooral bij regression testing is automatisering handig, omdat dezelfde tests na iedere wijziging opnieuw uitgevoerd kunnen worden. Hierdoor kan de kwaliteit van de software beter en efficiënter worden gecontroleerd.

TECHNOLOGIE

Mijn automation stack

🎭

Playwright

Voor het automatisch testen van webapplicaties gebruik ik Playwright. Hiermee kan ik bijvoorbeeld een browser openen, op knoppen klikken, formulieren invullen en gebruikersinteracties nabootsen. Vervolgens kan ik controleren of de applicatie het verwachte resultaat geeft. Playwright ondersteunt onder andere Chrome, Firefox en Safari en ik gebruik het voornamelijk voor end-to-end testing.

Daarnaast kan ik met Playwright ook mocks gebruiken voor externe (third-party) providers, zodat afhankelijkheden van bijvoorbeeld API’s of andere externe diensten tijdens het testen gecontroleerd kunnen worden nagebootst.

⌨️

TypeScript

Voor het schrijven van mijn geautomatiseerde tests gebruik ik JavaScript en TypeScript. Met JavaScript kan ik onder andere testlogica schrijven, gegevens verwerken en interactie met webapplicaties automatiseren.

TypeScript is gebaseerd op JavaScript en voegt onder andere statische typering toe. Dit helpt mij om fouten al tijdens het ontwikkelen van mijn tests te ontdekken. Daarnaast zorgt TypeScript ervoor dat mijn testcode overzichtelijker en beter onderhoudbaar blijft.

⚙️

Cypress

Cypress gebruik ik als testframework voor het automatisch testen van webapplicaties. Wat ik prettig vind aan Cypress is dat het relatief eenvoudig te installeren en te gebruiken is. Daarnaast biedt het een gebruiksvriendelijke testomgeving waarin ik mijn tests eenvoudig kan uitvoeren en resultaten kan bekijken.

⚙️

Node.js

Node.js gebruik ik als runtime-omgeving om JavaScript en TypeScript buiten de browser uit te voeren. Binnen mijn testomgeving gebruik ik Node.js onder andere om tests met Cypress en Playwright uit te voeren en om testresultaten te verwerken.

⚙️

Dev tools

Met Developer Tools, de ingebouwde hulpmiddelen van moderne webbrowsers, kan ik webapplicaties inspecteren, testen en debuggen. Ik gebruik deze tools onder andere om de HTML- en CSS-structuur te bekijken, JavaScript-fouten te onderzoeken en netwerkverkeer te analyseren. Ook kan ik hiermee het gedrag van een webpagina tijdens het gebruik controleren. Dit helpt mij om problemen sneller te vinden en te begrijpen waar ze vandaan komen.

TESTS

Wat ik automatiseer

🔗

End-to-End Tests

Met End-to-End Tests controleer ik een complete applicatie van begin tot eind. Hierbij controleer ik of een volledige gebruikershandeling goed werkt, bijvoorbeeld het inloggen, invullen van een formulier en uitvoeren van een actie. Op deze manier controleer ik of alle onderdelen van het systeem goed met elkaar samenwerken.

🖥️

UI Tests

Bij UI Tests controleer ik of de gebruikersinterface van een applicatie goed werkt. Hierbij test ik bijvoorbeeld of knoppen, menu’s, formulieren en links correct reageren wanneer een gebruiker ermee werkt. Zo kan ik controleren of de applicatie gebruiksvriendelijk en functioneel werkt.

🔌

API Tests

Met API Tests controleer ik of een API correct werkt en goed communiceert tussen verschillende systemen of onderdelen van een applicatie. Hierbij test ik bijvoorbeeld of de juiste gegevens worden verstuurd, ontvangen en verwerkt. Ook controleer ik of de API de juiste foutmeldingen geeft wanneer er iets misgaat.
